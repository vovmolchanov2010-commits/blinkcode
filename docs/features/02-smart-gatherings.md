# 2. Умные сборы

**Приоритет:** P0 · **Фаза:** MVP · **Оценка:** 6–7 чн

## Суть

Организатор ставит точку и примерное время сбора. Участники отмечают, через сколько будут, и добавляют комментарий («застрял в пробке»). Если участник делится геолокацией, ETA считается автоматически.

## Пользовательские истории

- Как организатор, я хочу за 10 секунд создать сбор «Бар на Покровке, 20:00» и позвать нескольких друзей или группу.
- Как участник, я хочу одним тапом сказать «буду через 15 мин» и добавить комментарий.
- Как организатор, я хочу видеть список: кто уже на месте, кто в пути и с каким ETA, кто опаздывает.
- Как участник, я не хочу вручную обновлять статус — пусть приложение само считает ETA по моему маршруту.
- Как участник, я хочу получить напоминание, когда пора выходить.

## Основной сценарий

1. «+» на карте → «Собрать друзей» → выбор точки (долгий тап по карте / поиск места / «где я сейчас»).
2. Время: «через 30 мин», «в 20:00», «примерно вечером» (интервал).
3. Выбор участников (друзья / группа) → отправка.
4. Участник видит карточку сбора: Иду / Не смогу / Позже отвечу.
5. Ответ «Иду» → быстрые статусы-чипы: `Выхожу` · `В пути` · `Застрял в пробке` · `Опоздаю на 10 мин` · `На месте` + свободный комментарий до 140 символов.
6. Если включён «авто-ETA» — ETA считается по маршруту и обновляется сам; ручной статус имеет приоритет на 15 мин.
7. Статус «На месте» ставится автоматически при входе в геозону 100 м.
8. Экран сбора: карта с участниками, список по ETA, лента статусов, чат сбора.
9. Сбор завершается, когда все пришли, организатор закрыл его или прошло 3 часа после назначенного времени.

## Критерии приёмки

- [ ] Создание сбора — не больше 3 экранов/шагов.
- [ ] Участник без включённого шаринга геолокации может участвовать только с ручными статусами.
- [ ] Авто-ETA пересчитывается не реже раза в 60 с при движении; при `ETA > назначенное время + 5 мин` участник получает подсказку «Похоже, опаздываешь. Сообщить?» (не отправляем за него автоматически).
- [ ] Автоматический статус «На месте» при входе в геозону 100 м; ручная отмена.
- [ ] Напоминание «пора выходить» = назначенное время − ETA − 5 мин (если ETA известен), иначе за 30 мин.
- [ ] Организатор может сдвинуть время/точку — все участники получают уведомление с диффом «20:00 → 20:30».
- [ ] На iOS — Live Activity с обратным отсчётом и числом пришедших, на Android — постоянное уведомление (в последние 60 мин до сбора).
- [ ] После завершения сбора точные позиции участников больше не видны в контексте сбора.

## Техническая реализация

- **Сущности:** `gatherings(id, owner_id, place_id|lat,lng, title, starts_at, window_minutes, status)`, `gathering_participants(gathering_id, user_id, rsvp, eta_at, eta_source[auto|manual], status_chip, comment, arrived_at)`.
- **Авто-ETA:** сервер раз в N секунд считает ETA через Matrix API по последним позициям участников (батч на весь сбор — 1 запрос на N участников).
- **Геозона прибытия:** проверяется на сервере по входящим позициям (не тратим лимит системных геозон на устройстве).
- **Real-time:** канал `gathering:{id}` в WebSocket; push только на значимые события (кто-то опаздывает, кто-то пришёл, изменилось время).
- **Связь с фичами:** из карточки сбора — «Маршрут» (фича 1) и «Рация» (фича 6, только для участников сбора).

## Ограничения и риски

| Риск | Что делаем |
|---|---|
| Спам-уведомлениями при большом сборе | Агрегация пушей («3 человека уже на месте»), тихий режим для сбора |
| Неточный ETA в пробках/метро | Показываем ETA как диапазон, ручной статус перекрывает авто |
| Приглашения от незнакомцев | Звать можно только друзей / участников своих групп |

## Метрики

- Сборы на WAU в неделю (цель ≥ 0.3).
- Доля сборов, где пришли ≥ 2 участника.
- Доля участников с авто-ETA vs ручными статусами.
- Число сообщений «ты где?» в чате сбора (должно падать — качественная метрика из исследований).

## MVP / потом

- **MVP:** создание, RSVP, ручные статусы + комментарий, авто-ETA, авто-«На месте», напоминание, чат сбора.
- **Потом:** голосование за время/место, повторяющиеся сборы («пятничный бар»), Live Activity, «опоздал — с тебя кофе» (геймификация опозданий), интеграция с календарём.
