# 7. SOS с live-трансляцией маршрута

**Приоритет:** P0 · **Фаза:** MVP · **Оценка:** 5–6 чн

## Суть

Кнопка SOS отправляет трём доверенным контактам не просто точку, а **ссылку на live-трансляцию маршрута на 15 минут**. Даже если человек не может говорить, друзья видят, куда он движется.

> **Важно:** SOS **дополняет**, а не заменяет звонок 112. На экране SOS всегда есть кнопка «Позвонить 112», а в описании фичи — явная оговорка, что приложение не является экстренной службой.

## Пользовательские истории

- Как пользователь, я хочу заранее выбрать до трёх доверенных контактов — в том числе тех, у кого нет приложения.
- Как пользователь в опасной ситуации, я хочу активировать SOS незаметно и быстро, не разблокируя телефон.
- Как доверенный контакт, я хочу открыть ссылку в любом браузере и видеть позицию в реальном времени, направление движения, заряд батареи.
- Как пользователь, я хочу отменить ложное срабатывание, но так, чтобы злоумышленник не мог просто «нажать отмену».

## Основной сценарий

1. **Настройка (онбординг или настройки):** выбор до 3 контактов (из друзей в приложении или по номеру телефона), тестовый режим «проверить SOS».
2. **Активация** (любой способ):
   - удержание кнопки SOS в приложении 3 с (с обратным отсчётом и вибрацией);
   - виджет на экране блокировки / Control Center (iOS 18+) / Quick Settings tile (Android);
   - Action Button / ярлык через App Intents (iOS).
3. **Сразу после активации:**
   - контактам с приложением — критический push + экран на весь экран;
   - всем контактам — **SMS со ссылкой** (отправляется сервером);
   - на устройстве — повышенная частота геолокации (1 раз в 5 с), запись трека.
4. **Ссылка** открывает веб-страницу (без установки приложения): карта, текущая точка, трек, скорость/направление, время последнего обновления, заряд батареи, кнопка «Позвонить».
5. **Через 15 минут** трансляция заканчивается, если пользователь её не продлил. Если устройство пропало из сети — страница показывает последнюю точку и «нет связи с N мин».
6. **Отмена:** только ввод PIN/биометрия. Контактам уходит «Отменено пользователем».

## Критерии приёмки

- [ ] От активации до отправки SMS и push на сервере — ≤ 5 с при наличии сети.
- [ ] Если сети нет в момент активации — событие в очереди на устройстве, отправка при первом подключении; пользователь видит статус «ожидание сети».
- [ ] Ссылка — длинный неугадываемый токен, срок жизни = длительность сессии + 1 ч, затем показывает «Трансляция завершена» без данных.
- [ ] Веб-страница обновляет позицию не реже раза в 10 с и работает в мобильных браузерах без логина.
- [ ] Отмена только по PIN/биометрии; ложная активация без отмены не может быть «тихо» убрана.
- [ ] Кнопка «Позвонить 112» доступна на экране SOS в один тап.
- [ ] Тестовый режим отправляет контактам сообщение с пометкой «ТЕСТ».
- [ ] Данные трека SOS удаляются через 30 дней (если пользователь не сохранил их явно).

## Техническая реализация

- **Сущности:** `trusted_contacts(user_id, contact_user_id|phone, position)`, `sos_sessions(id, user_id, token_hash, status, started_at, expires_at, cancelled_at)`, `sos_points(session_id, ts, lat, lng, accuracy, battery)`.
- **Отправка SMS:** провайдер SMS (зависит от рынка) с ретраями; при ошибке — фолбэк на второго провайдера.
- **Веб-страница:** лёгкий статичный фронт + WebSocket/SSE `sos:{token}`; без сторонних трекеров и аналитики.
- **Надёжность:** SOS-сервис изолирован от остального API (отдельная очередь/воркеры), мониторинг и алерты дежурному.
- **Push:** iOS Critical Alerts требуют отдельного entitlement от Apple — подаём заявку заранее; без него — Time Sensitive уведомления.

## Ограничения и риски

| Риск | Что делаем |
|---|---|
| Пользователь полагается на SOS вместо 112 | Оговорка, кнопка 112, формулировки в интерфейсе |
| Ложные срабатывания | Удержание 3 с, обратный отсчёт, тестовый режим |
| Злоумышленник отменяет SOS | Отмена только PIN/биометрией. «PIN под принуждением» (показывает отмену, но трансляция продолжается) — v1.1 |
| Нет сети / нет GPS | Очередь на устройстве, последняя известная точка, статус «нет связи» |
| Утечка ссылки | Неугадываемый токен, короткий TTL, нет индексации (`noindex`) |
| Ответственность | Юридическая проверка пользовательского соглашения до запуска |

## Метрики

- Доля пользователей с настроенными контактами (цель ≥ 20%).
- Время доставки SMS p95; доля успешно доставленных.
- Ложные срабатывания (отменены < 30 с) — должно быть низко.

## MVP / потом

- **MVP:** до 3 контактов, активация из приложения и виджета, SMS + push, веб-страница, 15 мин + продление, отмена по PIN, тестовый режим.
- **Потом:** PIN под принуждением, автоматическая аудиозапись (после юр. проверки), «проводи меня» (таймер возвращения домой: если не дошёл — авто-SOS), детект падения/аварии.
