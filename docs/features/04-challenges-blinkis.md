# 4. Челлендж «Чекак 2.0» и блинкисы

**Приоритет:** P2 · **Фаза:** v1.2 · **Оценка:** 8–10 чн (включая магазин)

## Суть

Пользователь просит идею челленджа — приложение выдаёт задание («сфотографируй большое дерево»). За выполнение начисляются **блинкисы** — внутренняя валюта, на которую покупаются кастомные стикерпаки, рамки для аватарок и прочая косметика.

## Пользовательские истории

- Как пользователь, я хочу нажать «Дай челлендж» и получить задание, выполнимое рядом со мной прямо сейчас.
- Как пользователь, я хочу выполнить его, сфотографировав результат, и сразу получить блинкисы.
- Как пользователь, я хочу делать челленджи вместе с друзьями (общий челлендж для сбора).
- Как пользователь, я хочу тратить блинкисы на стикерпаки, рамки, скины пина на карте.

## Основной сценарий

1. «Дай челлендж» → выбор сложности (лёгкий/средний/сложный) → задание + награда (5 / 15 / 30 блинкисов).
2. Можно сменить задание (1 бесплатная замена в день, дальше — за блинкисы).
3. Выполнение: фото **только из камеры приложения** (не из галереи) → проверка → начисление.
4. Фото опционально публикуется в ленту друзей; друзья ставят реакции.
5. Магазин: стикерпаки, рамки аватарок, скины пина, темы карты, эмодзи для стикеров (фича 5).

## Откуда берутся челленджи

| Источник | Плюсы | Минусы |
|---|---|---|
| Курируемый пул (200–500 заданий) | Безопасно, предсказуемо | Быстро приедается |
| Генерация LLM с контекстом (время суток, погода, сезон, типы мест рядом) | Бесконечное разнообразие, «здесь и сейчас» | Нужна фильтрация безопасности, стоимость |

**Рекомендация:** гибрид. LLM генерирует по шаблонам-категориям («найти», «сфотографировать», «попробовать») с жёсткими ограничениями, ответ проходит через фильтр безопасности + стоп-лист; курируемый пул — фолбэк.

**Запрещённые классы челленджей:** опасные для жизни, нарушающие закон (проникновение на закрытые территории, граффити), съёмка посторонних людей крупным планом, челленджи, требующие трат денег.

## Проверка выполнения

1. Фото только из встроенной камеры + геометка + время (защита от повторного использования).
2. Перцептивный хэш (pHash) — блокируем повтор одного и того же фото.
3. Vision-модель оценивает соответствие фото заданию → `confidence`.
   - высокая — автоматическое начисление;
   - средняя — «подтверди у друга»: любой друг подтверждает, начисление после;
   - низкая — отказ с подсказкой «попробуй ещё раз».
4. Лимиты: не больше N челленджей в день, суточный потолок блинкисов.

## Экономика блинкисов

- **Только зарабатываются** (челленджи, достижения из фичи 3, ежедневный стрик). Покупка за деньги — не в v1.
  - Почему: продажа цифровых товаров обязывает использовать IAP App Store / Google Play (комиссия 15–30%), появляются требования к валюте, возвратам и спорам. Сначала проверяем вовлечённость.
- **Учёт — журнал транзакций (ledger)**, а не поле `balance`: `wallet_transactions(id, user_id, amount, reason, ref_id, created_at)`; баланс = сумма; операции идемпотентны по `ref_id`.
- **Баланс экономики:** цель — 1 косметический предмет за ~1–2 недели умеренной активности. Таблица цен и наград — в конфиге, меняется без релиза.

## Критерии приёмки

- [ ] Задание выдаётся < 3 с; при недоступности LLM — из курируемого пула.
- [ ] Галерея недоступна для загрузки фото челленджа.
- [ ] Повторное фото (по pHash) отклоняется.
- [ ] Начисление идемпотентно: двойной тап / ретрай сети не даёт двойных блинкисов.
- [ ] Покупка в магазине атомарна: списание + выдача предмета в одной транзакции.
- [ ] Каждый сгенерированный челлендж прошёл фильтр безопасности; есть кнопка «пожаловаться на задание».

## Техническая реализация

- Сервис `challenges`: генерация (LLM API с поддержкой изображений), проверка, лимиты.
- Сущности: `challenges`, `challenge_assignments(user_id, challenge_id, status, expires_at)`, `challenge_submissions(photo_url, phash, model_verdict, confidence, verified_by)`, `shop_items`, `inventory`, `wallet_transactions`.
- Фото — в S3-совместимом хранилище, приватные ссылки с истекающим сроком.

## Ограничения и риски

| Риск | Что делаем |
|---|---|
| Опасный/неуместный челлендж от LLM | Шаблоны, фильтр, стоп-лист, жалобы, ручной ревью новых шаблонов |
| Накрутка блинкисов | Только камера приложения, pHash, лимиты, подтверждение другом |
| Стоимость vision-проверок | Дешёвая модель, лимит заданий в день, кэш однотипных |
| Инфляция валюты | Ledger + аналитика эмиссии/расходов, цены в конфиге |
| Фото с посторонними людьми | Подсказки в задании, детект лиц → размытие перед публикацией (v1.3) |

## Метрики

- Доля DAU, взявших челлендж; доля выполненных.
- Блинкисы: эмиссия / потрачено в неделю, медианный баланс.
- Покупки в магазине на активного пользователя; retention у делающих челленджи.

## MVP / потом

- **v1.2:** соло-челленджи, курируемый пул + LLM-генерация, проверка фото, блинкисы, магазин с 2 категориями (стикерпаки, рамки).
- **Потом:** групповые челленджи в сборах, сезонные события, челленджи от друзей друг другу, покупка блинкисов за деньги (после анализа экономики).
