# 9. Импорт любимых мест и авто-«дом/работа»

**Приоритет:** P0 (урезанно) / P1 · **Фаза:** MVP + v1.1 · **Оценка:** 3–5 чн

## Суть

При первом запуске предложить импортировать избранные места (дом, работа, любимые бары). Приложение сразу строит «вашу карту» и предлагает друзьям видеть, когда вы «дома» или «на работе», без ручной настройки геозон.

## ⚠️ Техническая реальность

Прямой импорт «одной кнопкой» **невозможен**:

- **Google Maps** не даёт публичного API для чтения сохранённых мест пользователя.
- **Apple Maps** не даёт сторонним приложениям доступа к «Избранному» пользователя.

Поэтому цель фичи («сразу своя карта без ручной настройки») достигаем комбинацией способов:

| Способ | Трение | Когда |
|---|---|---|
| **A. Быстрый выбор «Дом» и «Работа»** — поиск адреса с автодополнением или «я сейчас дома» | Низкое | Онбординг, MVP |
| **B. Авто-определение** — через 3–7 дней анализ стоянок: ночью → «дом», будни днём → «работа»; предложение «Похоже, это твой дом?» | Нулевое | MVP |
| **C. «Поделиться» из карт** — в Google/Apple/Яндекс Картах «Поделиться» → наше приложение, парсим ссылку и добавляем место | Низкое, по одному месту | v1.1 |
| **D. Импорт из Google Takeout** — пользователь выгружает «Сохранённые места» (GeoJSON/CSV) и загружает файл | Высокое | v1.1, как опция для энтузиастов |

## Пользовательские истории

- Как новый пользователь, я хочу за 20 секунд указать дом и работу и сразу видеть «свою карту».
- Как пользователь, я хочу, чтобы приложение само догадалось, где мой дом, и спросило подтверждение.
- Как пользователь, я хочу решать, кто из друзей видит статус «дома» / «на работе» — и что видят они только статус, а не адрес.
- Как пользователь, я хочу перенести любимые места из Google Maps.

## Основной сценарий (онбординг)

1. После выдачи прав на геолокацию: «Отметь дом и работу — друзья будут видеть статус, а не адрес».
2. Варианты: «Я сейчас дома» / поиск адреса / «Пропустить — определи сам».
3. Экран приватности: кто видит статусы (все друзья / близкие / никто). По умолчанию — **близкие друзья**.
4. Через 3–7 дней, если пропустил: «Похоже, это твой дом. Подтвердить?»
5. В настройках «Мои места» — добавить из «Поделиться», импорт Takeout, ручное добавление любимых мест (бары, спортзал), которые становятся точками на «моей карте» и в сборах.

## Критерии приёмки

- [ ] Онбординг дома/работы — ≤ 2 экранов, можно пропустить.
- [ ] Авто-определение работает **на устройстве** (кластеризация стоянок), на сервер уходит только подтверждённая точка.
- [ ] Ничего не публикуется без подтверждения пользователя.
- [ ] Друзья видят статус «🏠 Дома» / «💼 На работе», точная позиция внутри этих зон **размывается** до уровня статуса (настраивается).
- [ ] Импорт Takeout поддерживает формат GeoJSON «Сохранённые места»; некорректный файл — понятная ошибка; повторный импорт не создаёт дублей.
- [ ] Определение «дома/работы» использует серверную проверку по позициям, а не системные геозоны (iOS ограничивает приложение ~20 отслеживаемыми регионами, Android — 100 геозонами); системные геозоны — только как триггер пробуждения для 2 ключевых мест.

## Техническая реализация

- **Сущности:** `saved_places(id, user_id, kind[home|work|favorite], label, geom, radius_m, source[manual|auto|share|takeout], visibility)`.
- **Авто-определение:** алгоритм кластеризации стоянок (например, DBSCAN по точкам с остановкой ≥ 15 мин) на устройстве; «дом» — кластер с максимальным временем 22:00–07:00, «работа» — будни 10:00–18:00.
- **Парсинг ссылок «Поделиться»:** поддержка коротких ссылок Google Maps, Apple Maps, Яндекс Карт → координаты + название.
- **Takeout:** загрузка файла → парсинг на устройстве → отправка на сервер только выбранных пользователем мест.

## Ограничения и риски

| Риск | Что делаем |
|---|---|
| Ожидание «импорта в один клик», которого не будет | Честная формулировка в UI; ценность даёт авто-определение |
| Раскрытие адреса дома | Только статус, размытие позиции в зоне, видимость по умолчанию — близкие |
| Ошибки авто-определения (ночные смены, общежитие) | Всегда спрашиваем подтверждение, легко исправить |

## Метрики

- Доля новых пользователей, отметивших дом/работу в первые 7 дней.
- Точность авто-предложений (доля подтверждённых).
- Доля пользователей, открывших статусы «дома/на работе» друзьям.

## MVP / потом

- **MVP:** способы A + B, статусы «дома/на работе», приватность.
- **v1.1:** способы C + D, любимые места на «моей карте», места как быстрые точки для сборов.
