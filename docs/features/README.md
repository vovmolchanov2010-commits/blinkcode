# Спецификации фич

Каждая спецификация построена по одному шаблону:

1. **Суть** — одна-две фразы.
2. **Пользовательские истории**.
3. **Основной сценарий (flow)**.
4. **Критерии приёмки** — по ним QA и PM принимают фичу.
5. **Техническая реализация**.
6. **Ограничения и риски**.
7. **Метрики успеха**.
8. **Срез MVP / что потом**.
9. **Оценка трудозатрат** — грубая, в человеко-неделях (чн), до декомпозиции.
