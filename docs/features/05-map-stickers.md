# 5. Стикеры на карте

**Приоритет:** P1 · **Фаза:** v1.1 · **Оценка:** 4–5 чн

## Суть

Пользователь «прикрепляет» стикер к конкретному месту (кафе, парк, здание) с коротким комментарием. Друзья видят: «Витя оставил здесь стикер 🍕 — тут лучшая шаурма». Получается социальная карта рекомендаций от своих.

## Пользовательские истории

- Как пользователь, я хочу оставить стикер на месте, где мне понравилось, чтобы друзья узнали.
- Как пользователь, я хочу видеть на карте стикеры друзей рядом со мной и фильтровать их («еда», «бары», «виды»).
- Как пользователь, я хочу получить уведомление, когда я рядом с местом, где друг оставил стикер (opt-in).
- Как пользователь, я хочу решать, кто видит мой стикер: все друзья / близкие / только я (личные заметки).

## Основной сценарий

1. Тап по месту на карте (или «Я здесь» → ближайшие места) → «Оставить стикер».
2. Выбор стикера (стандартные эмодзи + купленные стикерпаки из фичи 4) + текст до 140 символов + видимость.
3. Стикер появляется на слое «Стикеры» у друзей; в ленте — «Витя оставил стикер в „Шаурме на Чистых“».
4. Друзья ставят реакции, отвечают («подтверждаю 🔥»), сохраняют место себе.
5. Опционально: «Напоминать, когда я рядом» — пуш при входе в радиус 200 м.

## Критерии приёмки

- [ ] Стикер привязывается к **месту (POI)**, а не к произвольной координате; при отсутствии POI — к координате с адресом.
- [ ] Видимость: друзья / близкие друзья / только я. По умолчанию — друзья.
- [ ] На одном месте может быть несколько стикеров разных друзей — показываем кластер с аватарками.
- [ ] Слой стикеров включается/выключается; фильтр по категориям.
- [ ] Автор может удалить стикер; стикер можно скрыть/пожаловаться.
- [ ] Стикеры на «домашней» геозоне автора запрещены (защита от раскрытия адреса).
- [ ] Уведомление «рядом стикер друга» — не чаще 1 раза в 2 часа.

## Техническая реализация

- **База мест:** провайдер POI (Foursquare / 2ГИС / Яндекс / OSM — зависит от рынка).
  - ⚠️ У Google Places жёсткие ограничения на хранение данных — можно хранить только `place_id`; учитываем при выборе провайдера.
- **Сущности:** `places(id, provider, provider_place_id, name, category, geom)`, `place_stickers(id, author_id, place_id, sticker_id, text, visibility, created_at, expires_at?)`, `sticker_reactions`.
- **Выборка для карты:** PostGIS `ST_DWithin` по bbox экрана + фильтр по графу друзей + видимость; кэш тайлов по H3-ячейкам.
- **Уведомления «рядом»:** серверная проверка по позициям (не тратим системные геозоны).

## Ограничения и риски

| Риск | Что делаем |
|---|---|
| Оскорбительный текст / доксинг (адрес человека) | Только друзья видят; жалобы; автофильтр текста; запрет на дом-зоны |
| Пустая карта у новых пользователей | Подсказки «оставь первый стикер», стикеры как награды в челленджах |
| Стоимость/лицензия POI-провайдера | Кэш мест, выбор провайдера по рынку |

## Метрики

- Стикеров на активного пользователя в месяц.
- Доля пользователей, сходивших в место по стикеру друга (визит в радиусе 50 м в течение 14 дней после просмотра).
- Реакции на стикер.

## MVP / потом

- **v1.1:** стикеры на POI, видимость, слой на карте, реакции, удаление/жалобы.
- **Потом:** «напомнить, когда рядом», подборки («Витины топ-5 баров»), публичные стикеры для всех пользователей (с модерацией), стикеры с истечением срока («тут сейчас фестиваль»).
