# 8. Виджет с ближайшими друзьями

**Приоритет:** P1 · **Фаза:** v1.1 · **Оценка:** 4–5 чн

## Суть

Виджет на домашнем экране iOS/Android показывает 2–3 ближайших друзей на мини-карте без открытия приложения. Тап по аватарке — быстрый чат.

## Пользовательские истории

- Как пользователь, я хочу одним взглядом на домашний экран понять, кто из друзей рядом.
- Как пользователь, я хочу тапнуть по аватарке и сразу написать другу.

## Реальность платформ (важно для ожиданий)

| | iOS (WidgetKit) | Android (App Widgets / Jetpack Glance) |
|---|---|---|
| Частота обновления | Бюджет системы — порядка десятков обновлений в день; **не live** | Периодически (минимум ~15 мин через WorkManager) + обновление по push |
| Живая карта | ❌ Нельзя интерактивную карту — только статичная картинка | ❌ То же, картинка или свой отрисованный UI |
| Тап по элементу | ✅ Разные deep link для разных аватарок (medium/large) | ✅ Отдельные обработчики |
| Ограничение памяти | Жёсткий лимит памяти у расширения виджета | Мягче |

**Вывод:** «мини-карта» в виджете — это **снимок**, обновляемый раз в 15–30 минут или по значимому событию (друг пришёл/ушёл), с отметкой «обновлено 5 мин назад».

## Варианты дизайна

1. **Мини-карта** — статичный снимок карты (рендерится на сервере или через snapshotter на устройстве) с аватарками.
2. **«Радар»** — без карты: круг, аватарки по направлению и расстоянию (300 м, 1.2 км). Легче, быстрее рендерится, лучше читается на маленьком размере.

**Рекомендация:** small-размер — «радар» с 1–2 друзьями; medium — мини-карта со снимком + 3 аватарки с расстоянием. Решение подтверждаем на прототипах с пользователями.

## Критерии приёмки

- [ ] Размеры: small (1–2 друга), medium (3 друга + карта), на iOS — виджет экрана блокировки (ближайший друг + расстояние).
- [ ] Показываются только друзья, которые делятся геолокацией с пользователем; «призраки» не показываются.
- [ ] Виден возраст данных («5 мин назад»).
- [ ] Тап по аватарке → чат с другом (deep link `app://chat/{userId}`); тап по пустому месту → карта.
- [ ] Виджет не увеличивает фоновый расход батареи более чем на 0.5% в сутки.
- [ ] При выходе из аккаунта виджет очищается.

## Техническая реализация

- Общий контейнер данных (iOS App Group / Android shared storage): список ближайших друзей, вычисленный приложением или полученный с сервера.
- Обновление: silent push «список ближайших изменился» → приложение обновляет данные → `WidgetCenter.reloadTimelines` / `GlanceAppWidget.update`.
- Снимок карты: серверный рендер статичной карты (Static Maps API провайдера) с кэшем по H3-ячейке; аватарки накладываются на клиенте.
- Бонус: **Live Activities / Dynamic Island** для активного сбора (фича 2) и SOS (фича 7) — это как раз «живые» обновления, которых нет у виджетов.

## Метрики

- Доля пользователей с установленным виджетом.
- Тапы по виджету в день → открытые чаты.
- Влияние на retention у пользователей с виджетом.

## MVP / потом

- **v1.1:** small + medium на iOS и Android, deep link в чат, обновление по push.
- **Потом:** виджет экрана блокировки, интерактивные кнопки (iOS 17+): «Я в пути», «Позвать на сбор» прямо из виджета.
