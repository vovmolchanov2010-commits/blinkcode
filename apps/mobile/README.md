# @blinkcode/mobile

Приложение для iOS и Android на Expo (SDK 58, React Native, Expo Router).

## Что умеет

- вход по номеру телефона и коду из SMS, заполнение имени и ника при первом входе;
- карта друзей в реальном времени (WebSocket), карточка друга: давность позиции, расстояние, заряд;
- фоновая отправка геолокации (обновление при смещении на 50 м и не чаще раза в минуту);
- друзья: поиск по нику, заявки, принятие и отклонение;
- настройки для каждого друга: точно / примерно / скрыто, «близкий друг», удаление, блокировка;
- режим «призрак» (на час, до конца дня или пока не выключишь), выключение геолокации, выход;
- **умные сборы** (вкладка «Сборы»): точка на карте, время, кого звать; ответы «иду / не смогу»,
  быстрые статусы, комментарий, «буду через N мин», авто-ETA и авто-«на месте» по геолокации,
  подсказка «похоже, опаздываешь», перенос и закрытие сбора организатором;
- **дойти до друга**: живое расстояние и время по прямой, друг видит «идёт к тебе, будет через ~7 мин»
  и может остановить; пошаговый маршрут — кнопкой в Яндекс Карты;
- **SOS**: удержание кнопки 3 с, SMS трём доверенным контактам со ссылкой на live-трансляцию (15 мин,
  продление), отмена только по PIN, тестовый режим, кнопка «Позвонить 112»;
- **дом и работа**: «я сейчас дома / на работе», друзья видят статус 🏠 / 💼 вместо адреса.

## Готовый APK для Android

APK собирается в GitHub Actions (workflow **Android APK**) — Android SDK и Xcode на своём компьютере не нужны:

1. GitHub → **Actions → Android APK → Run workflow** (собирается и сам — на каждый PR и пуш в `main` с изменениями приложения).
2. Через 15–25 минут открой запуск и скачай APK из раздела **Artifacts** (архив с `app-release.apk`).
3. Перекинь файл на телефон и установи (Android попросит разрешить установку из этого источника).
4. На экране входа нажми **«Сервер: … · изменить»** и укажи адрес сервера: `192.168.1.5:3000`
   (компьютер с `npm start` в той же Wi-Fi) или `https://<IP>.sslip.io` (сервер в Yandex Cloud).

Адрес по умолчанию можно зашить в сборку: поле при ручном запуске или переменная репозитория `EXPO_PUBLIC_API_URL`
(Settings → Secrets and variables → Actions → Variables).

Сборка подписана debug-ключом — для теста. Для Google Play понадобится свой ключ подписи.

## Запуск

Самый простой способ — `npm start` из корня репозитория (см. корневой README): сервер в Docker и приложение в **Expo Go**.
В Expo Go не работает фоновая геолокация — для неё нужна development build:

```bash
# 1. Поднять API (см. apps/api/README.md)
docker compose up -d && pnpm dev

# 2. Собрать и запустить приложение (нужны Xcode или Android Studio)
cd apps/mobile
EXPO_PUBLIC_API_URL=http://<IP компьютера>:3000 npx expo run:ios      # или run:android
```

Без локальных Xcode и Android Studio можно собрать development build в облаке:
`npx eas-cli@latest build --profile development`.

### Переменные

| Переменная | Зачем |
|---|---|
| `EXPO_PUBLIC_API_URL` | Адрес API. По умолчанию `http://localhost:3000`; для эмулятора Android — `http://10.0.2.2:3000`, для телефона — IP компьютера в локальной сети |
| `EXPO_PUBLIC_MAP_STYLE_URL` | Стиль карты MapLibre. По умолчанию OpenFreeMap (`https://tiles.openfreemap.org/styles/liberty`) — без ключа |

Код для входа в разработке приходит не по SMS, а в лог API: `SMS: Код для входа: 123456`.

## Проверки

```bash
pnpm typecheck
pnpm test        # логика из src/lib: клиент API, real-time, форматирование
```

## Структура

```
src/
  app/              экраны (Expo Router)
    _layout.tsx     провайдеры и защита маршрутов: вход → профиль → вкладки
    sign-in.tsx     вход по телефону
    setup.tsx       имя и ник при первом входе
    (tabs)/         карта, сборы, друзья, профиль
    friend/[id].tsx настройки друга
    gathering/      новый сбор и экран сбора
    route/[id].tsx  маршрут до друга
    sos/            кнопка SOS и настройка контактов / PIN
    places.tsx      дом и работа
  lib/              логика без React Native (покрыта тестами)
    api.ts          клиент API: токены, обновление, повтор после 401
    realtime.ts     WebSocket с переподключением
    friendLocations.ts  применение событий к позициям друзей
    meet.ts         сборы и маршрут: ETA, статусы участников, ссылки в Яндекс Карты
  services/         нативное: хранение токенов, фоновая геолокация
  state/            контексты и хуки: вход, real-time, друзья, сборы, маршруты, всплывающие события
  ui/               общие компоненты и цвета
    map/            карта: MapLibre в приложении, react-native-maps в Expo Go
```

Токены хранятся в Keychain / Keystore (`expo-secure-store`) с доступом после первой разблокировки —
иначе фоновая задача не сможет отправлять позицию при заблокированном экране.
